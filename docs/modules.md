
# AI Study Companion – Project Modules

## 1. Dashboard Module
Displays the overview of study activities.

## 2. Notes Module
Creates, views, edits and organizes study notes.

## 3. Task Management Module
Manages study tasks, deadlines and completion status.

## 4. AI Study Assistant Module
Provides AI-powered explanations or summaries based on student input.

## 5. Quiz and Revision Module
Supports quizzes, revision questions and flashcards.

## 6. Progress Tracking Module
Tracks study progress and completed activities.

## 7. User/Profile Module
Manages student profile and preferences if included.
